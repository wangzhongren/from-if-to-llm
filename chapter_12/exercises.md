## 1. 平均，还是求和

`context_vector` 里用的是 `.mean(axis=0)`。把它换成 `.sum(axis=0)`，再跑一遍。

**问题一**：`experiment.py` 实验二那个小任务的准确率变了吗？
（我们跑出来：5 个句子还是全对，差值一个数都没变。）

**问题二**：为什么换成求和完全没影响？

**问题三**：`after.py` 里"把某个词拿掉，看向量变了多少"那张表呢？
求和版本下，拿掉「发布」和拿掉「我」的变化量分别是多少？还"差不多"吗？

**提示**：余弦相似度只看方向，不看长短。而求和的向量是平均的向量乘 10，
方向一模一样。但"拿掉一个词"衡量的是**长度**的变化 ——
这个量在两种版本下完全不是一回事。

## 2. 窗口开多大

`context_vector` 现在用的是整句。改成只看左右各 1 个词：

```python
left = max(0, position - 1)
right = min(len(sentence), position + 2)
window = [ids[i] for i in range(left, right) if i != position]
return table_data[window].mean(axis=0)
```

再跑 `experiment.py` 实验二。

我们跑出来的结果：

| 句子 | 整句平均的差值 | 窗口 = 1 的差值 |
|---|---|---|
| 苹果 很 好吃 | +0.634 | +0.520 |
| 苹果 很 甜 | +0.666 | +0.520 |
| 苹果 发布 新 手机 | -0.729 | -0.245 |
| 苹果 发布 新 芯片 | -0.639 | -0.245 |
| 我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机 | -0.696 | **-0.058** |

**问题**：
- 5 个句子还是全对。但最后那句的差值从 -0.696 掉到了 -0.058 —— 这意味什么？
- 窗口该开 1 个词、2 个词还是整句？你能说清楚哪个"对"吗？

**提示**：-0.058 是个几乎平局的结果。换个随机种子、加一句话，
它可能就翻到正数那边去了。**一个靠运气才判对的答案，不算判对。**

## 3. 上下文向量最像句中的哪个词

在长句 `我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机` 里，
算一下 苹果 的上下文向量和**句中每一个词**的相似度，从高到低排。

我们跑出来的排序：

```text
   的     +0.477
   新     +0.377
   手机   +0.305
   看到   +0.273
   发布   +0.267
   刚刚   +0.193
   商场   +0.049
   在     +0.047
   我     -0.056
   昨天   -0.109
```

**问题一**：排第一的是「的」。如果让你按"这个词对 苹果 在这句话里的意思
有多重要"来排，你会把「的」排第几？「发布」呢？

**问题二**：排最后的两个是「我」和「昨天」。它们真的不重要吗？
把「昨天」换成「明天」，苹果 的意思变了吗？

**问题三**：这张排序表是平均法自己算出来的，还是我们人为规定的？

## 4. 换个词，表示一模一样

本章的表示法是：

```python
context(i) = 周围所有词的向量的平均
```

**注意式子里没有"第 i 个词自己"。**

**任务一**：在长句 `我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机` 里，
把位置 5 上的 苹果 换成 香蕉，算出来的上下文向量和原来比，差多少？

我们跑出来的结果：差 0.0000000，一个数都不差。

**任务二**：把 苹果 换成 小王、换成 的、换成 商场 —— 结果都一样。

**问题**：
- 这句话里的"苹果"到底是哪个词，这个信息在上下文向量里还剩多少？
- 那"这个词是什么"这件事，模型还能从哪里知道？
- 这个"不看自己"的性质，什么时候是优点，什么时候是致命的缺点？

**提示**：先去 `after.py` 里把 `context_vector` 那三行读一遍，
看看 `position` 这个参数到底用在哪里了。

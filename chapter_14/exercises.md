## 3. 只缩放，不换 V

把 `attention` 的最后一行改成混原始向量：

```python
return weights @ value, weights      # 改成
return weights @ vectors, weights    # 这样
```

跑一遍。输出的形状还一样吗？数值差多少？

想一想：权重决定"看谁"，value 决定"看到什么"。如果两个都不分家，
第 13 章的毛病会不会回来？

## 4. 自己造一个问法

在最后一节里，把问的维度换成第 1 维（时间）：

```python
for dim in [5, 4, 1]:
```

- `苹果` 现在会去问谁？
- 它问得到东西吗？为什么？（提示：看看 `苹果` 的向量里，时间那一维是多少。）
- 如果一个词身上根本没有那一维的信息，它问出来的权重会是什么样？

这一题说明的是：query 是"我在找什么"，但如果**我身上没有那个东西**，
我连问题都问不出来。

## 6. 换成另一句话的问题

拿第 15 章要用的那句话想想（先不用写代码）：

```text
小王 把 书 给了 小李 因为 他 明天 考试
```

如果让"他"去问"指代"（谁是"他"），它应该关注哪几个词？
如果让它去问"时间"（他什么时候考试），它又该关注哪几个词？

这两个问题的答案需要同一行权重去满足——把它们的理想权重各写一遍，
看看加起来是不是超过 1 了。

## 2. 把 embedding 拆掉会怎样

第 10 章我们说"编号没有意义"，所以我们给每个字符配了一组可以学的数字。

现在做个破坏性实验：把 embedding 表换成一个单位矩阵（每个字符是一个 one-hot 向量），也就是取消掉"字符可以有相似度"这件事。

做法：把 `NextCharModel.__init__` 里的

```python
self.table = randn(vocab_size, dim, scale=0.3, requires_grad=True, seed=seed)
```

换成

```python
self.table = Tensor(np.eye(vocab_size, dim), requires_grad=False)
```

（记得把 `DIM` 设成 33，不然形状对不上。）

- loss 和准确率各是多少？（我这边跑出来 loss 从 0.0026 涨到了 0.0175，准确率还是 100%。）
- 准确率没掉，loss 却涨了。这两件事怎么能同时成立？
- 这个改动其实说明了什么？——提示：`embedding` 之后接的那个线性层，输入是 `WINDOW * DIM` 维，输出是 `VOCAB_SIZE` 维。如果 `table` 只是一个固定的一一映射，那么这个线性层做的事情等价于一个什么东西？

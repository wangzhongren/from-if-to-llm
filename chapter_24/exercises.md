## 5. 给它一段真正没见过的东西

这一章最难受的地方是：我们的语料里没有一句"它没见过但合语法"的中文。所以"背还是学"这个判断做不了。

现在试着造一句。做法：从两首诗里取字，拼出一句**语料里没出现过、但看起来还算通顺**的句子。比如：

```python
NEW_SENTENCE = "明月光疑是地上霜举头望明月低头思故乡"   # 这是语料里的，不算
```

试试这些（自己判断哪些"像中文"）：

```python
"床前明月低头上霜"
"白毛浮绿水低头思故乡"
"举头望明毛浮绿"
"故乡鹅曲项向天歌水"
```

对每一句，量 `evaluate_text` 的困惑度，再用人眼看一遍。

- 哪一句的困惑度最低？它是不是也是你觉得最通顺的那一句？
- 有没有哪一句，你觉得通顺，但困惑度很高？反过来呢？

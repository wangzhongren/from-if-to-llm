# 第 15 章 练习

改 `after.py` 里的东西，重跑，看输出有没有变。

## 1. 只留一个头

把 `NUM_HEADS` 改成 1：

```python
NUM_HEADS = 1
```

跑一遍，回答：

- "他"这个位置现在有几行权重？
- 它的最大值是多少？和 4 个头的时候比起来呢？
- 损失还能降到很低吗？（能。数据只有两句话，一个头也背得下来。）
- 那为什么还要 4 个头？

---

## 2. 把头开得更多

把 `NUM_HEADS` 改成 8 或 12，跑一遍。

- 每个头的维度变成了多少？（`DIM // NUM_HEADS`）
- 头多了以后，权重矩阵还能看清吗？每个头关注的东西还一样吗？
- 把 `NUM_HEADS` 改成 5 会怎么样？（`24 // 5 = 4`，剩下的 4 维去哪了？）
  这是 `DIM` 必须能被头数整除的原因。

---

## 3. 换个种子

把 `train(steps=400)` 换成 `train(steps=400, seed=7)`，多试几个种子。

- 4 个头的"他"那一行，每次都不一样吗？
- 有没有哪个头**每次**都在看同一个词？
- 想清楚一件事：数据只有两句话，我们**不能**说"头 1 就是负责指代的"。
  那我们能确定说的是什么？

---

## 4. 让几个头共用一套 Q/K/V

把 `multi_head_attention` 里的三行改成只用第 0 个头的投影：

```python
query = vectors @ params["w_q"][0:1]
key = vectors @ params["w_k"][0:1]
value = vectors @ params["w_v"][0:1]
```

再跑一遍。4 个头的权重矩阵现在一样吗？

（这就是"多头"这个名字的意义：**不一样的地方在于每个头有自己的投影**，
不是简单地多算几遍。）

---

## 5. 把拼接换成相加

`multi_head_attention` 的最后一行做的是"拼起来再投影"。试着改成"加起来"：

```python
joined = head_output.sum(axis=0)      # (词数, 每个头的维度)
```

形状对得上吗？跑起来报什么错？如果想让形状对得上，`w_o` 应该改成什么形状？
想一想：拼接和相加，哪个保留的信息更多？

# 第 17 章 练习

## 1. 亲眼看看 8 层的 nan

把 `after.py` 最后一段的 `AttentionStack(n_layers=4)` 改成 `n_layers=8`，跑一遍。

你会看到 loss 从第 1 步就已经是几十甚至上百，然后很快变成 `nan`。

**问题**：`nan` 是从第几步开始出现的？把打印间隔改成每 10 步一次，找出来。

## 2. 旧写法到底能撑几层

在 `before.py` 里把 `n_layers` 依次改成 1、2、3、4，各跑一遍，把"最终 loss"填成一张表。

**问题**：它是慢慢变差的，还是到某一层突然断掉的？这个"断点"和两句话的长度（11 个词）有关系吗？

## 3. 给残差打个折

把 `after.py` 里的这一行：

```python
x = x + self.attention(x, layer)
```

改成：

```python
x = 0.5 * x + self.attention(x, layer)
```

再跑 4 层和 8 层。

**问题**：8 层能跑起来了吗？为什么给残差打折不等于"少加了几次"，而等于"每加一次，旧信息就衰减一点"？（提示：展开 3 层看看 `x` 里每一项前面乘了什么。）

## 4. 量一量"数值在涨"

在 `after.py` 的 `forward` 里加一行统计：

```python
for layer in self.layers:
    x = x + self.attention(x, layer)
    print(f"标准差 = {x.data.std():.4f}")
```

分别跑 1 层、2 层、4 层。

**问题**：4 层跑完，标准差是第 1 层的几倍？如果层数是 L，你觉得它大概和 L 的什么关系（`L`？`sqrt(L)`？`2**L`？）？换成 `x = 0.5 * x + ...` 之后还成立吗？

## 5. 残差能不能救"浅"模型

把 `before.py` 的层数改回 1，再把 forward 里那一行改成 `x = x + self.attention(x, layer)`，跑一遍。

**问题**：效果和原来的 1 层比，是变好、变差、还是差不多？这说明残差连接解决的是"深"的问题，还是"拟合能力"的问题？

## 6. 想一想：为什么"照抄"这么重要

本章的任务最省事的解法是"照抄输入"。我们把这句话换个说法：

> 一个 `L` 层的网络，如果想表达"什么都不做"，需要学多少东西？

**问题**：在"替换"式里，每一层都要学一个恒等映射；在"加上"式里，每一层只要学一个接近 0 的输出。哪种更容易学？想想第 8 章的 ReLU：`relu(x)` 想让输出恒等于 0，只要让权重变成负数就行了 —— 而想让一整层 attention 近似恒等，得让 `Q`、`K`、`V`、`O` 四个矩阵配合得多好？

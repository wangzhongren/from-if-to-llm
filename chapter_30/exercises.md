# 第 30 章练习

## 1. 给两张考卷都出点难题

把 `after.py` 里的 `TEST_SET` 扩到 30 句，故意包含：

- 一句话里同时有科技词和食品词（比如"苹果手机很甜"）；
- 只有新词、没有老词的句子（比如"大米发布新平板"）；
- 语法通但语义怪的句子（比如"香蕉发布新手机"）；
- 完全不像话的句子（比如"床前明月光"）。

然后跑 `experiment.py`，看两张成绩单各是多少。

- 规则那边掉分了吗？掉在哪几句？为什么？
- 模型那边掉分了吗？它的概率值（"把握"）在难题上有什么变化？
- 哪一边的失败更"可解释"？

## 2. 加第三个类别

现在只有"科技 / 食品"两类。试着加第三类"天气"，语料里对应的句子比如：

```python
WEATHER_SENTENCES = ["今天很冷", "明天很热", "今天有风", "昨天下雨"]
```

分别数一数：**模型那半边要改几行代码？规则那半边要改几行？**

- 模型：`LABELS` 加一项、语料里加几句、`CHARS` 会自动收集新字 —— 你改了几个地方？
- 规则：你需要新写哪些 if？新词表要几个人去想？
- 再加到 10 类呢？100 类呢？两边各自会变成什么样？

（这就是第 2 章那个问题的现代版本：**不是"要不要写规则"，
而是"规则的扩张成本是不是线性的"。**）

## 4. 写一句"这本书没讲的东西"

最后一章的"它还解决不了什么"里列了六件事：真正的数据、分布式训练、
对齐细节、多模态、推理模型、以及"它到底理解了什么"。

挑一件你最想弄清楚的，写清楚这三件事：

1. 它在**这本书的哪个位置**会插进来？（比如"分布式训练"插在第 28 章后面，
   因为那时我们第一次想做大。）
2. 它需要哪些这本书**没讲过的**基础？（数学、系统、数据工程……）
3. 它会怎样改变你理解的"训练一个模型"这件事？

## 5. 给这本书补一章

选一个你觉得这本书跳过太快的点，写出那一章的八个小节标题
（本章的问题 / 最简单的尝试 / 实验 / 新机制 / Python 实现 / 它解决了什么 /
它还解决不了什么 / 练习），然后只写"本章的问题"和"新机制"这两节，各 200 字。

不能是"顺便讲讲卷积神经网络"这种没有来路的东西。

## 6. 最后一个练习：把它跑坏

这本书里的每个模型都很小、很乖。试试让它坏掉：

- 把学习率调大 100 倍（哪一章讲过会发生什么？）；
- 把语料打乱成随机字符（loss 会停在哪？为什么是那个数？）；
- 把 `block_size` 调到比句子还长（位置表会出什么问题？）；
- 把训练集的句子全部删掉，只留验证集（会怎样？）。

每弄坏一次，说清楚：**它坏了，是因为哪一章的那个零件不到位？**

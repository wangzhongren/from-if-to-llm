# 第 7 章练习

## 1. 自己画一遍那 4 个点

拿一张纸，横轴写 x1、纵轴写 x2，把 (0,0)、(0,1)、(1,0)、(1,1) 四个点画出来，
标上答案。然后拿一把尺子，试着摆出一条能全分对的线。

摆不出来就对了。**亲手试过一遍，比看别人试一遍记得牢。**

## 2. 把暴力搜索的步长改小

`experiment.py` 里那条暴力搜索，步长是 0.1。

改成 0.01 再跑一遍（时间大概是 10 倍）。最好的准确率会变吗？

为什么不会变？（提示：把 w1、w2、b 同时乘上 2，这条直线一点没变。
所以真正不同的直线，比 61³ 少得多。）

## 3. 换一个"一条直线能分开"的任务

把标签改成：两个数**有一个是 1** 就判 1，否则判 0。

先手算一下 4 个点的答案分别是什么，然后跑一遍训练，
看 loss 能不能降到 0.6931 以下。

再把它改成"**两个都是 1** 才判 1"，重跑一遍。

两个任务都能分开吗？和这一章的 XOR 差在哪里？
（提示：写下两个任务的 4 个答案，和 XOR 的 4 个答案比一比。）

## 4. 把中间层换成"共享权重"

现在的 `w1` 是每一个中间单元各有一套权重。

试着让所有中间单元共用同一套 `w1[0]`，也就是
`h[j] = w1[0][0] * x[0] + w1[0][1] * x[1] + b1[0]`，
所有 j 算出来的 h 完全一样。

这样改完，中间层还有意义吗？loss 会变成多少？

## 5. 中间层只剩 1 个单元，甚至 0 个

先把 `hidden_size` 设成 1 跑一遍，再把中间层的大小设成 0 跑一遍。

- 1 个单元的两层网络，比第 6 章那个一层模型能表达的东西更多吗？
- 0 个单元的时候 loss 是多少？这个模型还剩什么？

（把中间层的公式写出来就算出来了：
`h = w1[0] * x[0] + w1[1] * x[1] + b1`，`分数 = w2 * h + b2`。
把第一条代进第二条，看它长什么样。）

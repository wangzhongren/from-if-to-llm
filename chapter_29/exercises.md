## 5. 只学一个"打分"的模型

DPO 用一个公式绕过了"打分模型"。真实系统里更常见的做法是**分开两步**：
先训练一个给回答打分的模型（reward model），再用它来调语言模型。

试着用我们的模型做一个最简版：

```python
# 输入（问 + 答），输出一个分数
scorer = TinyLM(VOCAB_SIZE, dim=64, n_layer=2, n_head=4, block_size=32)
head = torch.nn.Linear(64, 1)     # 把最后一层的向量压成一个数
```

用偏好数据训练它：好回答的分数要比差回答高（可以用 `-log sigmoid(分数差)` 当 loss）。

- 训练完以后，它会给没见过的回答打分吗？
- 用它给模型的生成结果打分，分数高的回答，人是不是真的更喜欢？
- 这个"打分模型"和语言模型是同一个东西吗？（提示：它们差在哪一层？）

## 6. 让模型学会说"我不知道"

现在模型对什么问题都答得很干脆，包括那些它其实不知道的。
给它加几句话是"不知道"的微调数据：

```python
("苹果", "辣", "苹果不辣。", "问：苹果辣吗？答：", "不辣。", "苹果是辣的。"),
```

（注意"苹果辣吗"的答案在预训练语料里根本没有——预训练文本里没有"辣"这个字。）

- 它会怎么回答"苹果辣吗"？先猜，再跑。
- 它答得对吗？它"知道"自己不知道吗？
- 这个问题（模型不知道自己不知道什么）在真实的大模型里叫什么？

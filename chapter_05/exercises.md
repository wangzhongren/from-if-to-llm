## 1. 手算一次 softmax 和损失

不许跑程序。用纸笔算「苹果芯片很强」在表 A 下的概率和损失。

表 A 给它两个分数：

```text
科技 1.0    食品 -1.0
```

第一步，算 `e 的 1.0 次方` 和 `e 的 -1.0 次方`：

```text
e^1  ≈ 2.7183
e^-1 ≈ 0.3679
```

第二步，加起来除以总和：

```text
科技的概率 = 2.7183 / (2.7183 + 0.3679) = 0.8808
```

第三步，算损失：

```text
损失 = -log(0.8808) = 0.127
```

算完跑 `experiment.py`，在实验二那张表里找这一行：

```text
  苹果芯片很强           2.0      1.00     0.127   只赢一点点，最勉强
```

对上了吗？

## 3. 换一把尺子（结果会让你愣一下）

把 `loss_of` 改成用"错误率"当损失：

```python
def loss_of(words, label):
    correct_index = CATEGORIES.index(label)
    return 1.0 - probability_of(words, correct_index)
```

跑一遍 `after.py`。

```text
轮数：26        最终损失：1.003e-11
```

**和用 `-log` 的时候一模一样。** 连轮数都不差。

为什么？想一步：只有两个类别的时候，`1 - 正确答案的概率` 等于什么？

（答案：它等于**错误类别的概率**。而"错误概率越小"和"正确概率越大"
是同一件事。两把尺子的刻度不同，但刻度之间的**顺序**是一样的——
所以"哪个更好"的判断完全一致。）

这说明了一件事：在这种"一次只试一个参数"的做法里，
尺子的顺序比尺子的数值更重要。

## 4. 拆掉 softmax 的保护

`softmax` 里有两行看着有点多余：

```python
biggest = max(scores)
exponentials = [math.exp(value - biggest) for value in scores]
```

试着把它改成最朴素的样子：

```python
exponentials = [math.exp(value) for value in scores]
```

然后跑一下：

```python
print(softmax([1000.0, 0.0]))
```

```text
OverflowError: math range error
```

为什么？`e` 的 1000 次方有多大？写下来数一数它有多少位数。

再想一步：减去最大值之后，`e` 的指数最大是 0，也就是最大不超过 1——
**这就是那两行的全部作用**。结果会不会变？（不会，分子分母同时缩小。）

## 6. 挑战题：为什么不能一次动所有参数？

现在 `adjust_weights_once` 一次只动一个参数，动完还要把整个语料重算一遍。

试着改成"一次动所有参数"：每个参数都按一个方向改一点，然后算一次损失。

你会撞上这几个问题：

- 每个参数该往哪个方向改？你手上有什么信息？（提示：只有一个损失值。）
- 如果全部改完之后损失变大了，你怎么知道是**哪一个**参数改坏了？
- 如果全部改完之后损失变小了，你怎么知道是不是某个参数改坏了、
  而另一些参数改得太好，把这个坏处盖住了？

这三个问题，就是下一章的全部内容。

## 4. 亲手画一张 scaling law 的图

把三个模型的（参数量，最低验证 loss）画成对数横轴：

```python
import math
for row in results:
    x = math.log(row["params"])          # 参数量取对数
    y = math.log(row["loss"])            # loss 也取对数
    print(f"{x:.2f}  {y:.2f}")
```

- 这些点大致在一条直线上吗？（幂律在对数-对数坐标里就是直线。）
- 三点确定一条直线，用这条直线外推：想要 loss 降到 0.45，需要多少参数？
  这个外推可信吗？为什么？（提示：想想本章那个"loss 下限"。）

## 3. 把归一化挪到残差后面

把 `after.py` 的这两行：

```python
handed = layer_norm(x, self.p["ln%d_w" % i], self.p["ln%d_b" % i])
x = x + self.attention(handed, layer)
```

改成：

```python
x = layer_norm(x + self.attention(x, layer), self.p["ln%d_w" % i], self.p["ln%d_b" % i])
```

（注意这时候 attention 拿到的是**没归一化**的 x。）

**问题**：8 层还学得会吗？跑出来的 loss 大概是多少？再想想：这一改，"残差那条直通车" 还在不在？（提示：梯度要回到上一层，得先穿过归一化。）

## 4. 自己实现一个 RMSNorm

"均值那一步可以省掉" —— 只除以均方根：

```text
rms = sqrt(mean(x 的平方))
y = x / rms * weight
```

在 `after.py` 里把 `layer_norm` 换成你自己写的这个版本（注意：这里不需要 bias 了），跑一遍 8 层。

**问题**：loss 和 LayerNorm 比怎么样？为什么"不减均值"也能用？（提示：减去的是一个常数，而这一步发生在一次线性变换之前 —— 线性变换可以自己把这个常数补回来，只要后面还有 bias。）

# 第 4 章 练习

这一章的代码只有 3 个函数。所以练习大多是"改掉一行，看它还能不能学"。

有意思的是：你会发现这一章的规则**非常结实**，改哪儿都不太坏。
这不是好事——它说明这条规则太粗糙了，粗到"怎么改都行"。

---

## 1. 每次改多少，真的不影响吗？

把 `after.py` 里的

```python
STEP = 1.0
```

改成 `0.001`，跑一遍。再改成 `1000.0`，跑一遍。

```text
三轮都是一模一样的：1  4  2  0
```

想一步：如果"每次改多少"完全不影响对错，那我们在训练里到底学到了什么？

（提示：看训练完的那张表，数字变大了还是变小了。）

---

## 2. 手动篡改三个 0

训练完之后，权重表里有 5 个词是 0：「电脑」「华为」「小米」「香蕉」「很」。

现在把它们手动改成 `[5.0, -5.0]`，再跑一遍 `measure(CORPUS)`：

```python
WEIGHT_TABLE["电脑"] = [5.0, -5.0]
WEIGHT_TABLE["华为"] = [5.0, -5.0]
WEIGHT_TABLE["小米"] = [5.0, -5.0]
print(measure(CORPUS))
```

```text
还是一样：10/10
```

想一步：这三个词被改成了完全不同的值，正确率一点没变。

- 那训练的时候，程序为什么不调它们？（提示：看 `train_one_round` 里那个 `continue`。）
- 一个"没被调整过"的权重，和一个"被反复调整过"的权重，在结果上有区别吗？

---

## 3. 把"减"去掉

`adjust` 里有两行：

```python
WEIGHT_TABLE[word][correct_index] += step
WEIGHT_TABLE[word][wrong_index] -= step
```

把第二行删掉（或者注释掉），只保留"给正确的那边加分"。

跑一遍。

```text
还能训到 10/10，训练轨迹也一模一样：1  4  2  0
```

为什么？想一步：我们判断类别，看的是两个分数**谁大**。
"给食品加 1 分"和"给科技减 1 分"，对"谁大"的影响有什么不同？

---

## 4. 故意喂它一个错的答案

把语料里「苹果很甜」的标签改成"科技"：

```python
("苹果很甜", "科技"),
```

（我们知道它是错的。程序不知道。）

重新训练，跑够 20 轮。

```text
它照样训到了 10/10——按照你给的标签算的 10/10。
```

想一步：程序"学会"了什么？它学会的是"这句话是科技"吗？还是别的什么？

再想：如果语料里 10 句的标签全是随机贴的，它会怎么样？

## 5. 手算一轮

不许跑程序。用纸笔算一遍：

**第一轮**里，处理到「苹果很好吃」这一句时，权重表发生了什么变化？

起始状态是全 0。你需要写下来：

- 这句话的两个分数各是多少？
- 程序答了什么？对不对？
- 这句话里有哪些词？每个词的两个权重各变成多少？

算完再跑一遍 `after.py`，看第一轮结束时「苹果」「很」「好吃」这三行是不是和你算的一样。

## 6. 挑战题：三个类别怎么办？

现在的语料只有两类：科技、食品。`CATEGORIES` 里也就两个名字。

假设我们手头的语料有三类（比如科技、食品、体育），`CATEGORIES` 里塞进三个名字。

`after.py` 的规则"答错了就把正确的加、错误的减"，能直接用在三个类别上吗？

试着列出来，你会撞上几个问题：

- 一句话被答成"食品"，但它其实是"体育"。这时候该改哪些权重？
- "打平了判科技"这条规矩，在三个类别里该怎么写？
- 更麻烦的：现在"答错了"是一个非黑即白的状态。
  如果程序答了"食品"，第二可能是"体育"，第三才是"科技"——
  这三种情况它在乎吗？

（第三个问题，第 5 章会回答。）

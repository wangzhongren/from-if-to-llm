# 第 13 章：不是每个词都一样重要

## 本章的问题

上一章我们用一个词的**上下文**来表示它：

```python
context = 其它所有词的平均      # 自己不算
```

这句话里的"苹果"靠上下文才能确定是公司而不是水果，方向是对的。但"平均"这个做法，
我们今天要当面拆穿它。

用的还是那句话：

```text
我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机
```

先跑 `before.py`，看第 12 章的做法在这句话上给出的"权重"：

```text
句子： 我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机

其实根本不用算，谁出了多少力是写死的：
------------------------------------------------------------
  我      0.10  ##############
  昨天    0.10  ##############
  在      0.10  ##############
  商场    0.10  ##############
  看到    0.10  ##############
  苹果    (自己)  （自己不在自己的上下文里）
  刚刚    0.10  ##############
  发布    0.10  ##############
  的      0.10  ##############
  新      0.10  ##############
  手机    0.10  ##############
  除自己以外的 10 个词，每个都是 1/10 = 0.10。
  '发布'是这样，'昨天'也是这样，'的'还是这样。
```

10 个词，一人一份，谁也不多谁也不少。

这不是"大概差不多"，是**一模一样**。为了看得更清楚，`before.py` 还做了一个扰动实验：
给第 i 个词的向量加一点点扰动（每个位置加的都是同一个向量），看"苹果"的上下文向量变化多少。
这个变化量就是这个词对"苹果"的影响力：

```text
  改的是哪个词              上下文向量变化了多少
  ----------------------------------------
  我                          0.028284
  昨天                        0.028284
  在                          0.028284
  商场                        0.028284
  看到                        0.028284
  刚刚                        0.028284
  发布                        0.028284
  的                          0.028284
  新                          0.028284
  手机                        0.028284

  最大变化 / 最小变化 = 1.000
  10 个位置，变化量一模一样 —— 平均法根本不知道谁重要。
```

改"发布"和改"昨天"，对"苹果"的影响完全一样。可我们一眼就看得出，
"发布""手机"和"苹果"是一回事，"昨天""商场"跟它没什么关系。

**问题摆在这里：平均法没有"重要"这个概念。** 它连一个能表达重要性的地方都没有——
权重是写死的 `1/10`，不是算出来的。

## 最简单的尝试

要修的地方很明确：**权重不能写死，要让模型自己算出来。**

那权重应该由什么决定？最直觉的答案是**相似度**：

> "苹果"和"手机"很像，所以"手机"说的话应该更算数；
> "苹果"和"昨天"不像，所以"昨天"说的话应该不重要。

这个想法谁都能想到，而且它有一个巨大的好处：**不用任何新东西**。
第 10 章我们已经有了词向量，两个向量像不像，直接算就是了。

于是最朴素的做法分三步：

1. **算分数**：中心词和每个词算一个相似度分数
2. **归一化成权重**：把分数变成一组加起来等于 1 的权重
3. **加权求和**：所有词的向量按权重混起来，变成中心词的新向量

第 3 步和第 12 章一样，只是把"平均"换成了"按权重平均"。真正新的是前两步。

## 新机制

三步，一步一个函数。

**第一步：算分数。** 两个向量有多像？最直接的做法是**点积**：逐维相乘再相加。

```python
score[i][j] = vectors[i] · vectors[j]
```

方向越一致分数越大。同样的两个词，交换顺序分数不变，因为点积是对称的。

**第二步：归一化成权重。** 分数可以是任意大小的正数，甚至是负数，不能直接当权重用。
我们要的是一组"概率"：每个都大于 0，加起来等于 1。这就是第 5 章那个 `softmax`：

```python
weights[i][j] = exp(score[i][j]) / sum_k exp(score[i][k])
```

它做的事情就一句话：**大的分数被放大，小的分数被压小，但一个都不清零。**

**第三步：加权求和。** 用权重把整句话的向量混起来：

```python
output[i] = sum_j weights[i][j] * vectors[j]
```

跑完这三步，每个词都得到了一个新向量。这个新向量不再是"这个词字典里的意思"，
而是"**在这句话里，这个词应该被理解成什么**"——它是别的词的加权混合。

`weights` 是一个方阵，第 i 行第 j 列的意思是：

> 第 i 个词在多大程度上"看着"第 j 个词。

这个矩阵，就是我们后面一路上要盯着看的东西。它是这套机制的全部秘密。

这套做法有个名字，从今天起我们叫它 **Attention（注意力）**。
名字挺唬人，其实说完就三句话：**算相似度 → 归一化 → 加权求和**。

## Python 实现

对应 `after.py`。核心就三个函数：

```python
def similarity_scores(vectors):
    """第一步：两两算相似度。"""
    return vectors @ vectors.T


def attention_weights(scores):
    """第二步：把分数变成权重，每一行加起来等于 1。"""
    return scores.softmax(axis=-1)


def attention_output(vectors, weights):
    """第三步：加权求和。"""
    return weights @ vectors
```

三个都只有一个矩阵乘法，因为这三步本来就是矩阵运算：

- `vectors` 的形状是 `(词数, 8)`
- `vectors @ vectors.T` 得到 `(词数, 词数)` 的分数矩阵
- `.softmax(axis=-1)` 沿着每一行归一化，得到权重矩阵
- `weights @ vectors` 得到 `(词数, 8)` 的新向量

## 它解决了什么

三件事，都有上面的数字撑着：

1. **权重不再写死。** 平均法的权重永远是 `1/10`，Attention 的权重是算出来的：
   `手机` 0.2208、`发布` 0.1495、`昨天` 0.0446，最大最小差 4.95 倍。
2. **影响力跟着权重走。** 扰动实验里，改一个词对"苹果"的影响，平均法是 0.028284 对所有人，
   Attention 是 0.078（手机）对 0.016（的）——4.89 倍。
3. **出来的向量有倾向了。** 平均法的上下文向量和所有词的相似度都挤在 0.33~0.64，
   Attention 的向量和"手机"0.92、和"我"0.10。

而且这套办法是**通用的**：`after.py` 最后试了三个不同的中心词——

```text
  苹果  最关注的三个词：手机(0.221)、苹果(0.198)、发布(0.149)
  手机  最关注的三个词：手机(0.251)、苹果(0.203)、发布(0.136)
  商场  最关注的三个词：商场(0.198)、在(0.105)、手机(0.103)
```

换个词看，就换一套权重。平均法在这里会打印三行一模一样的 0.1000。

## 它还解决不了什么

看 `苹果` 那一行：它把最多的注意力给了 `手机`（0.221）和 `发布`（0.149）。
这看起来挺对——但它是**碰巧**对的。

因为"看谁"这件事，完全由一件事决定：`苹果` 的向量和那个词的向量**像不像**。
而"像不像"是一个数，一个**对称**的数：

跑一下 `similarity_scores` 就能看到：分数矩阵是对称的，
`苹果 → 手机` 和 `手机 → 苹果` 都是同一个数 `1.600`。

这就麻烦了。假设我想让"苹果"这一行去关注**时间**——因为我想问"它是什么时候发布的"，
所以希望注意力压到"刚刚"上。做不到。原因很直接：

- "刚刚"和"苹果"的相似度是 **0.000**，它的权重被压在 0.0446，和"的"一模一样。
- 我能调的东西只有一个：`苹果` 自己的向量。但那个向量同时还在扮演另一个角色——
  它是**别人看苹果时**用的那个向量。我把它改成"想找时间"的样子，
  别人看"苹果"的方式也跟着变了。

也就是说，现在只有**一把尺子**：像不像。可"我在找什么"和"我有什么"明明是两件事：

- 我在找什么：我想知道"什么时候发布的" → 这是一个**提问的方向**
- 我有什么：这个词身上带着"时间"这个信息 → 这是**被问的内容**

一把尺子量两个角色，就只能得到"它俩像不像"这一个数字。

**那么，怎么才能让"我在找什么"和"我有什么"分开？**

## 练习

见 `exercises.md`，这里列最关键的几条：

1. **不归一化会怎样**——把 `attention_weights` 改成直接返回分数，看权重还加不加起来等于 1，
   哪些词变成了 0 或负数。
2. **把 softmax 变"硬"**——只给分数最高的词权重 1，其余给 0。看 `苹果` 变成了谁的向量，
   再想想第 9 章那个 `backward()` 还能不能走下去。
3. **换一种"像"**——把点积换成余弦相似度，看权重之间的差距是变大还是变小。
4. **句子里多一个无关的词**——加一个"香蕉"，看平均法和 Attention 各自受了多大影响。
5. **让"看的人"变成另一个人**——改 `苹果` 的向量，看"苹果看谁"和"谁看苹果"是不是一起变了。

# 第 13 章 练习

改 `after.py` 里的函数，重跑，看输出有没有变。每题都给一个能自己验证的结论。

---

## 1. 不归一化会怎样

把 `attention_weights` 改成"直接返回分数"，也就是不算 softmax：

```python
def attention_weights(scores):
    return scores
```

跑一遍 `after.py`。

- 看 `苹果` 那一行：权重还加起来等于 1 吗？
- 看新向量：它的长度是变大了还是变小了？
- 哪些词的权重变成了 0 或负数？

然后把 softmax 换回来，只把"减掉最大值"那一步去掉（提示：如果没有减最大值，遇到分数很大的情况会怎样）。想一想：为什么这一步不影响结果，却必须留着？

---

## 2. 把 softmax 变"硬"

把 `attention_weights` 换成"只给分数最高的那个词 1，其余给 0"（可以先用 `np.argmax` 找出来）。

跑一遍，回答：

- `苹果` 最终会变成谁的向量？它还能同时带上"发布"和"手机"的信息吗？
- 这个结果和"平均法"比起来，是另一个极端吗？

（提示：这就是很多年后人们说的"硬注意力"。它的毛病是没法求梯度——第 9 章那个 `backward()` 走不下去。）

---

## 3. 换一种"像"

把 `similarity_scores` 从点积换成余弦相似度：

```python
def similarity_scores(vectors):
    x = vectors.data
    x = x / np.linalg.norm(x, axis=-1, keepdims=True)
    return Tensor(x) @ Tensor(x).T
```

跑一遍。

- 权重之间的差距是变大了还是变小了？为什么？
- "商场"现在的权重是多少？和之前比变了多少？
- 点积和余弦，哪一个更关心"方向一致"，哪一个更关心"长度"？

---

## 4. 句子里多一个词

在 `EMBEDDINGS` 里加一个词，比如：

```python
"香蕉": [0.0, 0.0, 0.0, 0.0, 0.6, 0.0, 0.0, 0.0],
```

把句子改成 `我 昨天 在 商场 看到 苹果 刚刚 发布 的 新 手机 香蕉`，跑一遍。

- 平均法下，其它 10 个词的权重从 `1/10` 变成了多少？
- Attention 下，`苹果` 给"手机"的权重掉了多少？
- 一句话里多一个完全无关的词，对平均法的影响大，还是对 Attention 的影响大？

---

## 5. 让"看的人"变成另一个人

现在权重矩阵的第 i 行是"第 i 个词在看谁"。把 `苹果` 的向量改一改（比如把"科技与商业"那一维从 1.0 改成 0.0），再跑一遍。

- `苹果` 看谁变了没有？
- 别人看 `苹果` 的权重变了没有？

这两个问题的答案如果一样，说明在目前这套做法里，"我在找什么"和"我有什么"是同一件事——这正是下一章要拆开的东西。

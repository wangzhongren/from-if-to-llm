# 第 8 章练习

## 1. 用笔把那个括号乘开

数学部分只有一步，自己写一遍印象会深得多：

```text
h = w1 * x + b1
分数 = w2 * h + b2
```

把第一行代进第二行，得到 `分数 = (w2 * w1) * x + (w2 * b1 + b2)`。

然后把 10 层也写一遍：`分数 = W10 * (... W2 * (W1 * x + b1) + b2 ...) + b10`。

试着说服自己：不管多少层，最后都能写成 `A * x + B`。
（`A` 就是那一串矩阵乘起来的结果，`B` 是那一串偏置变换出来的。）

## 2. 换个"拐弯"的函数

### (a) leaky_relu

```python
def leaky_relu(value):
    """负数不变成 0，而是变成原来的 0.01 倍。"""
    return value if value > 0 else 0.01 * value
```

`forward` 和 `backward` 两处都要改（backward 里那个判断也要跟着改）。
改完跑一遍，XOR 还能解决吗？

### (b) step：这道题比较阴

```python
def step(value):
    """负数变 0，正数变 1。"""
    return 1.0 if value > 0 else 0.0
```

先想清楚它的导数是什么。（除了 `z = 0` 那一个点，斜率处处是 0。）

现在做两次实验：

1. **只换 `forward` 里那个函数**，`backward` 一个字都不动，跑一遍。
2. 再把 `backward` 也改"对"（`step` 的导数处处是 0，梯度全掐掉），跑一遍。

第一次居然还能跑，第二次才真的不动了。

那么问题来了：**第一次跑的时候，我们算出来的梯度，
到底是哪个函数的梯度？**

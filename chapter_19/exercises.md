# 第 19 章 练习

## 1. 换一个线性的标签

把 `after.py` 里 `make_probe` 的这一行：

```python
y = ((x[:, :, 0] > 0) ^ (x[:, :, 1] > 0)).astype(int)
```

改成"或"（两个数里只要有一个是正的就算 1）：

```python
y = ((x[:, :, 0] > 0) | (x[:, :, 1] > 0)).astype(int)
```

三种结构各跑一遍。

**问题**："或"是线性的（一条直线就能分开），"异或"不是。这次只有 Attention 的那个能学会吗？为什么？这个对比说明了什么？

## 2. 中间那一层不升维行不行

把 `after.py` 里 `W1` 的形状从 `(32, 128)` 改成 `(32, 32)`，`W2` 从 `(128, 32)` 改成 `(32, 32)`（相关的地方一起改），跑一遍 600 步。

**问题**：准确率掉到多少？如果掉下来了，说明"加工"这件事需要的是"中间留出足够宽的地方"，还是"有一个 ReLU 就行"？想一想：如果中间不升维，`线性 → ReLU → 线性`比一层线性多出来的东西到底有多少？

## 3. 把 ReLU 拿掉

把 `mlp` 里的 `.relu()` 去掉：

```python
def mlp(self, x, block):
    return (x @ block["W1"] + block["b1"]) @ block["W2"] + block["b2"]
```

跑一遍 600 步。

**问题**：准确率是多少？"两个线性层中间夹一个 ReLU"里的哪一部分，才是真正干活的那个？（提示：两个线性层叠在一起，等价于什么？）

## 4. 完整块的逐层统计

照第 18 章 `after.py` 的写法，给本章的块也打印一遍"每一层拿到手的东西"的标准差。

**问题**：一个块里有两次归一化（`ln1` 给 Attention，`ln2` 给 MLP）。它们各自管住的是哪一个张量？如果只留 `ln1`、把 `ln2` 去掉，训练还稳吗？

## 5. 位置 3 看得见位置 5 吗

在 `after.py` 里写一个小实验：把输入的第 5 个位置整体加上 100（`x[:, 5] += 100`），然后看第 3 个位置的输出变了多少。

**问题**：
- 只用 MLP 的模型，位置 3 的输出变了多少？
- 只用 Attention 的模型呢？
- 两种都有的模型呢？
- 再想一层：如果只把第 5 个位置**整体**加一个常数（每一维都加 100），为什么归一化之后，Attention 那边可能一点变化都没有？

## 6. 想一想：Attention 和 MLP 能不能互相替代

本章的实验说：交换只有 Attention 能做，加工只有 MLP 能做。

**问题**：那么"两个 MLP 叠起来"能不能替代一个 Attention？"两个 Attention 叠起来"能不能替代一个 MLP？（提示：从"一个位置能不能看到别的位置"和"输出能不能跑出输入的取值范围"这两个角度想。）
